# CarDoctor AI – Android MVP

Pirmais CarDoctor AI Android prototips.

## Kas jau darbojas
- Auto marka/modelis/gads/motors
- Simptomu ievade
- OBD koda ievade
- Lokāla diagnostikas loģika
- Riska līmenis
- Ieteicamā pārbaužu secība
- Daži populāri OBD kodi (P0401, P0299, P0234, P0101, P0087, P0300, P2002)
- Darbojas arī bez interneta

## APK būvēšana GitHub
Projektā ir `.github/workflows/build-apk.yml`.
Pēc projekta ielikšanas GitHub:
1. Atver Actions
2. Izvēlies "Build CarDoctor AI APK"
3. Spied "Run workflow"
4. Kad build pabeigts, lejupielādē artefaktu "CarDoctorAI-APK"
5. Tajā būs `CarDoctorAI.apk`
